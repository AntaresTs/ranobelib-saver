# Коментари
Код не доведен до конечной фазы, роботоспособность не подтверждена.
Задачи:
- [] Получение информации о произведении и о каждой главе с сайта (json).
- [] Получение содержания главы с сайта (json).
- [] Парсинг json в более понятный формат
    - Информацию о произведении записать в одну структуру (descriptor)
    - Информацию о главах в удобной форме записать в другую структуру, и созадть вектор.
- [] Используя содержимое главы, скачать картинку и записать её точное место в тексте.
    - в итоге получится массив/вектор храняший содержимое каждого абзаца.
- [] написать функцию которая используя имеющиеся данные, будет собирать главы в формате `pdf` (Но это как будет удобно).
    - Главы собрать по пути `{author}-{Book-name}/book/tom-1-{tom_title}, tom-2-{tom_title}...` (но это еще не точно).
- [] Созданные главы объеденить в тома.
    - получится `{author}-{Book-name}/book/{author}-{Book-name}-T{tom number}.pdf`



# Скачивание книг с сайта ranobelib
Решил попробовать что то написать на C++. Этот проект является как бы обучающим для входа в C++.

Данный проект это программа для скачивания произведений с сайта ranobelib.me.

На сайте, в открытом доступе есть интересные для меня произведения, которых может не быть на rulate, и соответствено их проблемматично скачать иными способами. Так что этот проект призван упростить путь к возможности скачивать книги.
