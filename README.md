# Скачивание книг с сайта ranobelib
Решил попробовать что то написать на C++. Этот проект является как бы обучающим для входа в C++.

Данный проект это программа для скачивания произведений с сайта ranobelib.me.

На сайте, в открытом доступе есть интересные для меня произведения, которых может не быть на rulate, и соответствено их проблемматично скачать иными способами. Так что этот проект призван упростить путь к возможности скачивать книги.
